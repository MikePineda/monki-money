# Architecture

monkimoney is one Docker image running one Node process: the AdonisJS 7 API,
which also serves the Angular 22 PWA from the same origin. Postgres 17 is the
only stateful dependency; files go to S3-compatible storage.

```
Phone (installed PWA) --HTTPS--> Cloudflare (proxy, WAF, cache rules)
                                   |
                                   v
                     Traefik (Dokploy, Cloudflare-only allowlist)
                                   |
                                   v
               monkimoney-web (Swarm service, 1 replica, start-first)
               node: AdonisJS API  +  Angular build in build/public
                     |                        |
                     v                        v
           monkimoney-db (Postgres 17,   Cloudflare R2 bucket
           internal network only)        (CSV originals, private)
```

## Decisions

| Topic           | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Why                                                                                                                                                                                                                              |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| One image       | `Dockerfile` stages `gitsha -> deps -> build -> prod-deps -> runtime`; the API serves `build/public` (the Angular build).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | One deploy unit, same origin, no CORS.                                                                                                                                                                                           |
| Stateless       | No volume on the app container. Sessions in the encrypted cookie store, files in S3/R2, logs to stdout, rate limits in the database.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Start-first updates and replicas need any task to be disposable.                                                                                                                                                                 |
| Sessions        | Single `web` session guard (httpOnly, `secure` in production, `sameSite: lax`, cookie `monkimoney_session`, 30 days). The cookie holds only the user id, a `session_version` and the CSRF secret.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | No tokens in localStorage. "Log out everywhere" and password changes bump `users.session_version`, which a middleware compares on every request. Redis is a config switch if server-side sessions are ever needed.               |
| Storage         | `@adonisjs/drive` disk `s3` (`DRIVE_DISK=s3`): R2 in production (`S3_REGION=auto`), MinIO locally and in CI, path-style; `fs` only for tests (`drive.fake()`). Empty `DRIVE_DISK` = parse in memory and do not persist (bank CSVs are archived at `imports/{householdId}/{batchId}.csv`, best effort).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Stateless app; S3 does not block go-live.                                                                                                                                                                                        |
| Uploads         | **Images** (receipt photos) are optimised on the client first (longest side ≤ 1600 px, WebP/JPEG ~0.8, EXIF stripped) and go **directly from the client to R2** through a presigned `PUT` URL issued by the API (`POST /api/v1/uploads/presign`); the API reads the object back for the LLM and deletes it (1-day lifecycle rule as safety net; bucket CORS for the app origin). **Bank CSVs** (≤ 2 MB, monthly) are posted to the API (multipart, in memory) which parses them and archives the original in R2 itself; they may move to the presign flow later with no client contract change beyond the upload step.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Direct upload pays off for large files and scale; for small monthly CSVs the API path is simpler and needs no CORS for go-live. Owner decision 2026-10-15.                                                                       |
| Rate limiting   | `@adonisjs/limiter` with the `database` store (`memory` in tests).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Works across replicas without Redis.                                                                                                                                                                                             |
| Migrations      | `MIGRATE_ON_START=true` in `docker/entrypoint.mjs`, additive migrations only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Dokploy Applications have no pre-deploy hook. A failed migration means the task never turns healthy and Swarm rolls back. With replicas > 1, migrate out of band.                                                                |
| Multi-household | `households` + `household_members` + `users.current_household_id`; every resource carries `household_id` and is loaded through a household scope. A resource from another household answers **404, never 403**. A parametrised test covers every route with `:id`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | 403 leaks existence; cross-tenant access is the number one real risk.                                                                                                                                                            |
| Auth            | `web` session guard only. Login stamps `session_version` in the session; `verify_session_version` middleware rejects stale stamps (401). Shield CSRF on every mutation (`XSRF-TOKEN` cookie -> `X-XSRF-TOKEN`). `@adonisjs/limiter` throttles login/forgot/reset/invitations (5/min per IP + email, then 20 min) and API routes (300/min per user), keyed by `clientIp(ctx)` (`CF-Connecting-IP` when the TCP peer is the local proxy, else `request.ip()`). Passwords: scrypt N=2^17, r=8, p=1 (OWASP). Verify/reset links carry `encryption.encrypt` tokens with `purpose` + `expiresIn` (reset embeds `session_version` and applies it with one conditional UPDATE: single use, even concurrently). Invitation links are only ever emailed, never returned by the API. Email verification by link or by a 6-digit code typed in the PWA (only `sha256("<user id>:<code>")` stored, 15 min, 5 wrong attempts, rotated on resend). Cloudflare Turnstile (`TurnstileVerifier` container singleton, no-op while `TURNSTILE_SECRET` is empty) guards sign-up, login and forgot password before validation, credentials and throttles.                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Stateless revocation without a session table; tokens need no storage.                                                                                                                                                            |
| Tenancy rules   | `household_context_middleware` (after `auth` + verified email) loads the membership of `users.current_household_id` into `ctx.household` / `ctx.membership` (403 if none, or if the household is `pending_deletion` except restore). Lists use the `forHousehold` scope, rows `findInHousehold` (404), body ids are checked against the household (422). Roles via Bouncer `HouseholdPolicy` (owner: update, invite, export, delete). One user = one household in the MVP (enforced in services, not in the schema): members leave with `household.leave` (ledger rows kept), a verified user without one creates one with `households.store`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | A single code path for scoping keeps the 404 rule testable (`tests/functional/tenant_isolation.spec.ts` fails when an `:id` route lacks a case).                                                                                 |
| i18n            | `@adonisjs/i18n` catalogs `resources/lang/{en,es}/{validator,messages,errors,categories}.json` with a parity test. Locale: user -> `Accept-Language` -> household -> `APP_DEFAULT_LOCALE` (`en`). System categories store `name` + `is_system`; the API names them in the reader's locale from the shared taxonomy slugs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | One source of names (`packages/shared/src/taxonomy.ts`); partners can read in different languages.                                                                                                                               |
| Mail            | `@adonisjs/mail`, `MAIL_DRIVER=log\|resend\|smtp`; a missing key/host falls back to a logging no-op; send failures are logged, never thrown. Text-first, in the recipient's locale, links from `APP_URL`. Tests use `mail.fake()`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Mail can never break sign-up or leak from dev/tests.                                                                                                                                                                             |
| Ledger          | `transactions` (signed `amount_cents`: expenses negative, income positive; `date` = calendar date of the purchase, `bank_date` = posting date), `transaction_splits` (lines with their own category; `is_split` rows have no category and the lines sum to the amount), `transfers` (one row + two `transfer` legs, one per account, written in one DB transaction; legs are read-only through `/transactions`). `paid_by_user_id` NULL = joint; default payer = account owner → card suffix (`account_cards`) → creator. `client_id` (uuid, partial unique per household) makes creates idempotent, also under a race (23505 → existing row). Balances = opening + SUM per account (`cleared` vs `available` with pending); `opening_balance_cents` is the balance at the end of `opening_balance_date`, so with a date only rows dated after it count. Writes that read-then-write (transaction and transfer edits, split changes, account/category deletes) lock the row (`FOR UPDATE`) inside their DB transaction and decide from the locked state; deletes count references under that lock and a lost FK race answers 409. Reports are pure functions in `app/domain/reports` over postings that only `app/repositories/postings_repository.ts` produces (split lines flattened with `COALESCE(split.category_id, tx.category_id)`); `app/domain` cannot import models (ESLint). Income vs expense follows the category group, so a refund reduces its category; transfers never count. "Today" and "this month" come from the household time zone through the swappable `Clock` service. | One flattening query keeps every report consistent with the month screen; pure reports are unit tested without a database. Splits carry `household_id` so a household delete cascades them in one level (NO ACTION category FK). |
| Privacy         | `transactions.is_private` belongs to the payer (or the creator of a joint one); when that owner was deleted or left the household the row is ordinary again. For anyone else the API masks `payee`, `description`, `raw_description`, `tags`, `category_id`, split lines and the review flag (`isMasked: true`), excludes the row from text/category/review filters, skips it in bulk categorize, reports its amount under a `private` bucket (totals unchanged), masks it in exports and refuses writes (403 `E_TRANSACTION_PRIVATE`). One rule, `app/domain/ledger/privacy.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | A couples' app must not reveal a surprise gift; masking in one place keeps lists, reports, search and exports consistent.                                                                                                        |
| Imports         | Bank CSV -> pure pipeline (`app/importers`, `app/domain/importing`) -> `import_batches` / `import_rows` (one staged batch per account, unique `(household, account, external_hash)` so a row never comes back) -> person decides -> confirm in one DB transaction (batch `FOR UPDATE`) -> ledger + learned `merchant_rules`. Classification with the LLM runs as a job (`@adonisjs/queue`, `QUEUE_DRIVER=sync` = inline). Details: `docs/import-pipeline.md`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Staging stays under a second without the model; the model only sees rows nothing else could categorize, within the household quota.                                                                                              |
| Contract        | The Tuyau registry generated from the routes is the API contract (see `docs/CONTRACTS.md`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | The web typecheck breaks when the API changes shape.                                                                                                                                                                             |
| Versioning      | Conventional Commits + release-please (single root package). The image writes `.app-version` and `.git-sha`; `/api/health` reports both.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | One version for api + web + shared because they ship as one image.                                                                                                                                                               |
| CORS            | Disabled everywhere. Dev uses the `ng serve` proxy (`apps/web/proxy.conf.json`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Same origin keeps cookies simple.                                                                                                                                                                                                |

## Layout

API (`apps/api`): thin controllers (validate, call a service, transform),
services own use cases and DB transactions, `app/domain` is pure (no Lucid, no
I/O, no implicit `now`), repositories and scopes for tenancy, one concept per
file named after the concept. Web (`apps/web/src/app`): `core/` (API client,
session, i18n, theme, PWA), `domain/` (pure, no Angular), `shared/ui`,
`shared/charts`, `layouts/`, `features/<x>/{data-access,ui,feature}`.
Shared (`packages/shared`): wire types and pure helpers used by both sides,
compiled to `dist/` because Node does not load `.ts` from `node_modules`.

## Runtime surface today

| Route                                                                                        | Purpose                                                                                                                     |
| -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `GET /api/health`                                                                            | Readiness: database + heap checks, `{ status, version, sha, checks }`, 503 when a check fails. Statuses only, no internals. |
| `GET /api/health/live`                                                                       | Liveness: `{ status: 'ok' }`, touches nothing.                                                                              |
| `GET /api/v1/config`                                                                         | Public runtime config for the SPA.                                                                                          |
| `/api/v1/auth/*`, `/api/v1/me`                                                               | Sessions, sign-up, email verification, password reset, invitations, profile (see `docs/CONTRACTS.md`).                      |
| `/api/v1/household*`, `/api/v1/accounts*`, `/api/v1/category-groups*`, `/api/v1/categories*` | Household-scoped resources (see `docs/CONTRACTS.md`).                                                                       |
| `/api/v1/transactions*`, `/api/v1/transfers*`, `/api/v1/reports/*`                           | The ledger and its reports (see `docs/CONTRACTS.md`).                                                                       |
| static `public/`                                                                             | Angular build with the PWA cache policy.                                                                                    |
| `GET *` (last route)                                                                         | SPA fallback to `index.html`; unknown `/api/*` stays a JSON 404.                                                            |

## Build info

`.app-version` (from the root `package.json`) and `.git-sha` (from the
`gitsha` stage, or the `GIT_SHA` build arg) are written next to the compiled
API (`/app/apps/api/build` in the image). Non-empty `APP_VERSION` / `GIT_SHA`
env vars override them; without either the API reports `dev` / `unknown`.
