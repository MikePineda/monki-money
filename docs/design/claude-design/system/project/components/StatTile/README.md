# StatTile

Label in `caption` / `ink-2` (sentence case, no colon), value in `title` weight 600 with proportional figures, optional delta in `caption` / `ink-2` with a 16px arrow icon. The icon takes `status-good` when the change is favourable and `status-serious` when not; the words carry the meaning.

On Month, three tiles share one row separated by 1px `line` hairlines, not boxes. Tile values round to whole dollars; the hero and the table view keep cents.
