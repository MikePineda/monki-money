# SegmentedControl

Two to four mutually exclusive options. Track `surface-2`, radius 8, 44px tall, 4px inset; the thumb is `surface-1` with a 1px `line` hairline and radius 4. The selected option reads in `accent` at weight 600; others in `ink-2`. The thumb slides in 150ms ease-out.

Use it for Gasto / Ingreso / Transferencia in quick add and Todas / Dudosas / Nuevas in import review. Use chips instead when the user can pick several.
