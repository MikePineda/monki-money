# BottomSheet

The only modal surface. `surface-1`, top corners 16px (`radius-sheet`), `elevation-2` in light, over the `scrim`. A 32 × 4 handle in `line-strong`, a `heading` title, then content; max height 90% with internal scroll; a primary action, if any, is fixed at its bottom.

Enter 200ms, exit 150ms, ease-out; opacity only under reduced motion. Focus moves into the sheet and returns to the trigger on close.

**Select sheet**: 56px option rows; the selected one has a trailing `check` in `accent`. Add a search field past eight options.
