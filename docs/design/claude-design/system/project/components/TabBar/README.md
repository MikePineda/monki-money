# TabBar

Fixed bottom navigation: `surface-1`, 1px `line` top border, 64px plus the bottom safe area. Slots: Mes · Movimientos · **+** · Importar · Ajustes. Each tab is a 20px icon over a `caption` label; inactive `ink-3`, active `accent` at weight 600.

The centre add button is 48 × 48, radius 12, `ink-1` fill with a 24px `plus` in `surface-0` (a primary action, so ink like the primary button), inside the bar (not floating, no notch). Accessible name "Agregar movimiento"; it opens `/add`.
