# EmptyState

States the fact and the next step, with one action. A 48px `surface-2` square (radius 12) holding a 24px Lucide icon in `ink-3`, a `heading` title, one sentence in `body` / `ink-2`, and one button (primary when it is the screen's main job).

No illustrations, no jokes, no "¡Ups!". Example: "Aún no hay movimientos en octubre." / "Agrega el primero o importa el CSV de tu banco."
