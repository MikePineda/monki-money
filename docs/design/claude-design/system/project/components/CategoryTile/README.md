# CategoryTile

The 4 × 2 grid of the eight most-used categories in quick add. Tiles are 64px tall, radius 12, `surface-1` with a 1px `line`; a 20px Lucide icon in `ink-1` over the name in `caption` / `ink-2`. Selected: `accent-soft`, 1px `accent` border, icon and name in `accent`.

The eighth tile is always "Más", which opens the category select sheet. Category icons come from one fixed Lucide set; no emoji, no per-category colours.
