# Card

`surface-1`, 1px `line`, radius 12, 16px padding, no shadow. A card groups one thing: an insight, the install-app prompt, a settings group. Never nest cards, and don't wrap charts or lists in cards; sections are separated by whitespace and hairlines.

Insight card: an `eyebrow` label, one or two sentences in `body`, and an optional link action. The deterministic text and the later LLM text use the same slot.
