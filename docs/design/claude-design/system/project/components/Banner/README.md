# Banner

Persistent, inline news about the content below it. `surface-2`, radius 12, 16px padding, no border and no coloured side stripe. Leading 20px icon (`info` in `ink-2`, or a status icon in its status colour), message in `body` / `ink-1`, optional link action, dismissible with a 44px `x`.

Use for a new app version ("Actualizar"), offline, an import with warnings, a budget past 90%. Use a Toast for transient confirmations.
