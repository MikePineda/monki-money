# Chip

A 36px control (44px hit area) with radius 8 and `label` text. Not a pill.

- **Filter chip** at rest: `surface-1`, 1px `line-strong`, `ink-1` text, optional `chevron-down`. Selected: `accent-soft` fill, 1px `accent` border, `accent` text and a leading `check`.
- **Value chip**: shows the current value and opens a select sheet ("NAB Everyday ▾").
- **Person chip**: the 8px person dot (`person-a`, `person-b`, hollow `mark-muted` for shared) before the word. The word stays in ink.
