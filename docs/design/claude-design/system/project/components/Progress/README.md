# Progress

- **Linear** (`mm-progress`): 4px `surface-2` track with rounded ends; `ink-1` fill for task progress (CSV upload), with the figures in `caption` tabular / `ink-2`.
- **Meter** (budgets, later): `mark-neutral` fill; past 90% `status-serious`, past 100% `status-critical`, always with an icon and words ("92% usado").
- **Steps** (onboarding): "Paso 2 de 4" plus four 4px segments; done segments in `ink-1`.

The accent is not a progress colour.
